# 题库格式

## archive.json

在题库根目录放 `archive.json`。`id` 是题库标识，`subject` 为界面科目名，`code` 为装饰性短标签。章节按 `number` 排序；`shortName` 用在左侧导航。小节可以用字符串，也可以写 `{"name":"名称","number":2}` 明确指定编号。

若本地题库不可写，可以把同样的元数据放入 `config.local.json` 的 `archive` 对象，会覆盖题库文件的元数据。不同题库推荐使用不同 `data` 目录。

## question.json（推荐）

每题一个文件。必填 `stem`、`answer`，内容为非空 Markdown 文字。

| 字段 | 说明 |
| --- | --- |
| `id` | 推荐必填；全库唯一，字母/数字/点/下划线/短横线，最多120字。不要在后续修改时变更 |
| `number` | 正整数题号；省略时取目录名里的数字，否则为1 |
| `chapter`、`section` | 可选；省略时按相对路径前两层目录分组 |
| `type` | 任意非空题型名称；省略时按有无选项推断 |
| `title` | 可选，题目索引标题 |
| `stem` | 题干，Markdown |
| `options` | 可选数组，元素为 `{"label":"A","markdown":"内容"}`，标签 A–Z 不重复 |
| `answer` | 参考答案，Markdown |
| `explanation` | 可选解析，Markdown |
| `reference` | 可选参考资料，默认折叠 |
| `diagnostic` | 可选提取说明，默认折叠 |

公式可写 `$...$`、`$$...$$`、`\(...\)` 或 `\[...\]`。JSON 中反斜线需要转义，例如 `"$\\alpha$"`。

配图使用相对于该题文件的路径，文件必须在题库目录内。图示不会自动裁切或转录。源文件与图片保持只读。

同一题只放一种题目文件，避免重复导入。目录里的其他笔记 Markdown 不会作为题目导入。

## question.md / 题目与答案.md

支持以下结构，标题需对应；它不是任意 Markdown 的自动识题器。

````markdown
# 题目标题

## 题目信息
- **题型**：单项选择题

## 题目描述
题干……

### 选项
- A. 选项一
- B. 选项二
- C. 选项三
- D. 选项四

## 参考答案
B

## 详细解析
解析……

## 原书图表与页面对照
![参考页](page.png)
````

问答题不写选项，题型填“问答题”或其他名称。英文标题也支持 `Question`、`Answer`、`Explanation`、`Reference`。中文别名支持“题目”“答案”“解析”“参考资料”。

Markdown 题目的 ID 由题库标识和源文件相对路径生成。题干内容改动不会改变 ID；移动题目文件会。需要自由移动的题目请用显式 ID 的 JSON 格式。

## 导入提示

重复 ID、缺少答案、无法切分选项等会列在 `data/catalog.json` 的 `issues` 中。已有题目源文件暂时损坏时，会保留上一次有效快照。图片缺失会列在完整题目对象的 `warnings` 中。

自动分组的章节与小节按名称排序。希望固定顺序时，请写 `archive.json`；增加题目时保持原编号。
